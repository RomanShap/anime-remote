# Anime Remote

Расширение для Firefox: управляй видео с телефона. Переключай серии, ставь на паузу, перематывай, меняй громкость, включай весь экран. Пульт сам помнит, на какой серии и минуте ты остановился.

*A Firefox extension that turns your phone into a remote for video sites (animevost, kinogo, HDrezka and any page with a video player). No server to install: scan a QR code and you're done.*

## Установка

1. Скачай файл расширения `anime-remote-<версия>.xpi` из раздела [Releases](https://github.com/RomanShap/anime-remote/releases/latest) и открой его в Firefox (клик по файлу в панели загрузок или перетащи в окно Firefox), нажми «Добавить». Расширение подписано Mozilla.
2. Нажми значок пульта на панели Firefox. Появится QR-код.
3. Наведи на него камеру телефона и открой ссылку. Можно добавить страницу на главный экран.

Больше ничего ставить не нужно: ни Python, ни программы, ни настроек роутера. Телефон и компьютер могут быть в разных сетях (например, телефон на мобильном интернете).

Так же ставится на Steam Deck: Firefox из Discover, дальше шаги 1–3.

**Один раз на каждом сайте:** Firefox не даёт видео включаться со звуком, пока по странице не кликнули. Кликни один раз по странице с видео или разреши автовоспроизведение: значок слева в адресной строке → «Автовоспроизведение» → «Разрешить аудио и видео». Без этого пульт запустит видео без звука и подскажет на телефоне, что делать.

## Что умеет на каких сайтах

| Сайт | Пауза, перемотка, звук, весь экран | Серии | Где остановился |
|---|---|---|---|
| animevost.org | да | список серий, вперёд и назад, автопереход | серия и минута |
| kinogo и похожие сайты с встроенными плеерами | да | вперёд и назад, если в плеере есть плейлист (Playerjs, HDVB) или список серий | серия плейлиста и минута |
| HDrezka и зеркала | да | список серий и сезонов | серия и минута |
| любой другой сайт с видео | да | кнопки «следующая серия» в плеере, если они есть | минута |

animevost и kinogo проверены на настоящих страницах. Поддержка HDrezka написана по разметке её страниц, но не проверена: сайт закрыт проверкой на бота, которую автоматический тест не проходит. Если на HDrezka что-то не работает, [напиши](https://github.com/RomanShap/anime-remote/issues).

## Как это работает и что уходит в интернет

- Расширение и страница телефона находят друг друга через бесплатный сервер сообщений [ntfy.sh](https://ntfy.sh). После этого они говорят напрямую (WebRTC), обычно внутри домашней сети.
- Всё, что идёт через ntfy.sh, зашифровано. Ключ есть только в ссылке-приглашении, в её части после `#`, которая не отправляется ни на один сервер. ntfy.sh видит только зашифрованные данные и не хранит их.
- Если напрямую соединиться не удалось (бывает в некоторых сетях), команды идут через ntfy.sh, тоже зашифрованно. Это чуть медленнее, на телефоне написано «Связь через интернет». У ntfy.sh есть лимит, около 250 сообщений в день с одного адреса, поэтому в этом режиме пульт шлёт только заметные изменения.
- Страница пульта для телефона — это статичная страница на GitHub Pages ([docs/](docs/)). Никакой статистики и рекламы.
- Кто знает ссылку, тот может управлять видео в твоём браузере. Не выкладывай её. Новую ссылку можно сделать в окне расширения: «Ещё» → «Новая ссылка».
- «Где остановился» хранится только в браузере (на компьютере).

## Для разработчика

```
extension/     само расширение (Manifest V2, Firefox 140+)
docs/          страница пульта для телефона (GitHub Pages)
tools/pack.py  сборка: копирует общий protocol.js в docs/ и собирает dist/anime-remote-<версия>.zip
tools/mock_relay.py  локальная замена ntfy.sh для тестов
test/          проверки в отдельных Firefox через Marionette
```

**Сборка и подпись.** Firefox ставит только расширения, подписанные Mozilla. Подписать можно бесплатно, публиковать в каталоге не обязательно:

1. `python tools/pack.py` создаст `dist/anime-remote-<версия>.zip`.
2. На [addons.mozilla.org/developers](https://addons.mozilla.org/developers/) войди в свой аккаунт → «Submit a New Add-on» → «On your own» → загрузи этот zip.
3. Через несколько минут придёт письмо. Скачай подписанный `.xpi` со страницы версии и выложи его в Releases.

Для проверки без подписи: `about:debugging` → «Этот Firefox» → «Загрузить временное дополнение» → `extension/manifest.json`. До перезапуска Firefox.

**Тесты.** Каждая проверка запускает свои Firefox с временными профилями и не трогает твой браузер.

```bash
python tools/mock_relay.py --port 8777
python -m http.server 8778 --bind 127.0.0.1 --directory docs
python test/ext_e2e.py all
```

`ext_e2e.py` проверяет animevost (прямая связь), телефон без WebRTC (связь через ретранслятор) и kinogo. `real_relay_smoke.py` проверяет связь через настоящий ntfy.sh (несколько сообщений). `screenshots.py` снимает окно расширения и страницу телефона.

## Старый способ: сервер на Python

До расширения пульт работал через маленький сервер на компьютере (`server.py`) и скрипт для Violentmonkey (`anime-remote.user.js`). Они остались в репозитории и работают, но нужны, только если не хочется ставить расширение. Запуск: `Anime Remote.bat` на Windows или `bash start.sh` на Linux и Steam Deck. Телефон тогда открывает адрес, который печатает сервер, и должен быть в той же сети Wi‑Fi. Тесты этого способа: `test/run_test.py`, `test/run_progress.py`.
